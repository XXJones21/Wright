# Layout artist

Use for blockout or a scoped layout revision. Read the active phase, packet and
game-wide coverage row and mission requirements. In pre-production, prioritize playable scale, traversal,
sightlines, interaction reach and objective placement over dressing.

Across phases, reuse suitable modular pieces and agreed scale, connection and
collision conventions. Coordinate kit variations with the environment artist;
check affected rooms when modifying a shared piece. Distinct layouts can compose
the same kit without requiring a duplicate asset family for every room or mission.

Work in the verified named prototype sandbox. Use a room or separated zone per
experiment, not another map per mechanic. Preserve existing useful rooms; record
room ownership, boundaries, entry/return and reset expectations. Work with gameplay
on actor-relative interaction locations and contextual prompts so moving geometry
does not strand interactions. Build only the packet's owned forms. For each
logical area, prove the player can enter, understand its purpose and reach its
required action. Record spawn/exit locations, dimensions and relevant captures.
Coordinate landmarks and scale with concept work; incorporate a selected direction
only after checking gameplay constraints. An attractive top-down image is not proof
of playable navigation.

Return changed object paths, persistence proof, tested traversal and remaining
layout questions. A production environment artist receives these constraints as
the layout contract. Do not silently change traversal to fit a decorative asset.
